# Tinaab backend foundation

The browser is not trusted to decide reward amounts. Server-side rules cap each verified activity at ₦500. Unknown activity types receive no reward. Client-submitted amounts are validated but are never the source of truth. Claims remain pending until authentication, activity verification, anti-fraud checks and a persistent wallet ledger are added.

Next: authentication, database ledger, idempotency, anti-fraud, admin audit logs and payment-gateway adapter. Wallet balances and withdrawals remain server-controlled.
